# 1.0.47-beta.2 — Aircraft location, photos and automatic camera return

Fixes latitude/longitude inputs rejecting valid full-precision coordinates, including geocoder results.

Camera tiles now offer **Replace while aircraft nearby**. The aircraft card appears only while fresh airborne traffic matches the radius and altitude filters. The camera keeps decoding underneath and returns when traffic leaves or data becomes stale/unavailable. Dedicated aircraft tiles remain available. Existing beta.1 aircraft tiles can select a return camera and use conditional replacement.

Adds actual aircraft photos when available from Planespotters.net, with photographer credit and an icon fallback. Photos can be disabled. Registered owner, operating airline and destination are optional fields alongside callsign, altitude and speed. Owner and route lookups use adsbdb. **Destination (lookup)** is a callsign database match, not a confirmed live flight plan; it can differ from the aircraft's actual destination. Missing metadata stays unavailable.

Settings upgrade to schema 18. The first save keeps `settings.json.before-aircraft-details.json`; stop this beta and restore that backup before returning to beta.1. Stable rollback uses the earlier pre-aircraft backup.

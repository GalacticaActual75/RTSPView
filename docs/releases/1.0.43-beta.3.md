# RTSPView 1.0.43-beta.3

Fixes the nine reported interface and presentation issues (#1–#9).

- Layout previews fit the available browser height in landscape and portrait. Short screens use more compact controls, and small previews hide snapshot-age labels.
- Tile inspectors group focus-assignment buttons with clear spacing. The layout menu is labeled **Manage layout**.
- Saved host-restart acknowledgments disappear after applying and remain hidden on reload. Changing the schedule requires acknowledgment again.
- Completed PawnIO installation and maintenance-helper actions disappear when their corresponding host status confirms success.
- Diagnostics automatic-opening exclusions use labeled bypass switches. Automation rule cards match the panel theme.
- **System → Viewer → Show tile borders** can be turned off for a gapless wall. The preference applies to main streams and original overlay-source tiles.
- **Overlays → Overlay controls → Appearance → Overlay border** independently shows or hides each overlay's border using the standard tile color.
- Overlay circles, rounded rectangles, and custom masks use antialiased alpha edges instead of hard Windows region clipping. Video and controls share the same mask and opacity.

Validation: Release build with zero warnings/errors; configuration persistence, native viewer/layout, restart scheduling, layout preset/proportion, shape-editor and snapshot checks. Rendering checks verify transparent exterior, opaque interior and partially transparent edge pixels for circles, rounded rectangles and rotated custom shapes. Isolated browser checks cover preview fitting, focus controls, acknowledgment save/change behavior, completed installation controls, bypass switches and border save/reload behavior. No live camera-host installation was performed.

Stable remains 1.0.42.

# RTSPView 1.0.45

Promotes 1.0.45-beta.1 through beta.4 to stable, retaining the full stable 1.0.44 foundation.

## Weather

- Native weather tiles and **Weather Widgets** over camera streams, using Open-Meteo without a required API key for noncommercial use.
- Location search/manual coordinates, Fahrenheit/Celsius, current conditions and configurable forecast information.
- Presets and appearance controls with toggles, sliders, background opacity, text/icon sizes, alignment and placement. Minimal widgets fit their contents and retain selected high/low values.
- Labeled Weather Widget placeholders in the layout preview. Full-grid **Add weather** offers a camera chooser with widget or tile-replacement actions.
- Layout and weather creation work over ordinary LAN HTTP, with a regression test for browsers without `crypto.randomUUID()`.

Weather remains under **Layouts**. The stream overlay feature is now named **Picture in picture** throughout navigation and related controls.

## Settings and scope

Existing streams, automation and weather settings are preserved. Weather stays off until configured. Weather tiles are supported in standard layouts and one widget can be attached to each main camera; official severe-weather alerts and backdrop blur are not included.

Settings use schema 16. On the first settings save after upgrading from 1.0.44, `settings.json.before-weather.json` retains the original configuration. To downgrade to 1.0.44, stop RTSPView and restore that file as `settings.json` before using the older release. Normal configuration exports include weather settings.

Weather coordinates are sent to [Open-Meteo](https://open-meteo.com/). Cached requests are shared across tiles/widgets, typically refreshed every 15 minutes, and run separately from video playback. Attribution is shown on the cards; data is provided under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Validation and installation

Includes native weather/high-low rendering, camera playback continuity, configuration/security, automation/Tapo, update/restart and LAN HTTP layout regression checks. Beta.4 is published before promotion; the stable release workflow runs the regression suite again and builds its own Windows x64 installer.

Install below or choose **Settings → Updates → Stable**, check for updates and confirm installation. Refresh the web administration page after updating. Hosts on Beta stay on that channel until switched to Stable; changing channels does not install an update automatically.

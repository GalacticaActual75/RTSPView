# RTSPView 1.0.45-beta.4

- Renamed **Stream Overlays** to **Picture in picture** in navigation, headings, actions and related help.
- Renamed **Weather overlay** to **Weather Widget** in the layout editor, settings dialog, enable switch and preview placeholder. The save action is **Apply widget**.
- Weather Widgets remain under **Layouts**. Saved settings and existing placements are preserved.

Includes the weather features and fixes from beta.1–beta.3, based on stable v1.0.44. In particular, weather/layout creation works over ordinary LAN HTTP, and Minimal widgets retain selected high/low values.

Validation includes the LAN HTTP action regression, related choices, branding/privacy checks and the full Windows release workflow.

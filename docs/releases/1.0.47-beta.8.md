# RTSPView 1.0.47-beta.8

Weather and aircraft widgets can now be placed freely on a saved layout or anchored to a camera tile. Drag new layout widgets to move them and click to edit. Each belongs only to its layout; existing per-camera overlays remain supported.

- Four aircraft card designs, rounded photos, custom background colors and independent text sizes.
- Separate fade-in and fade-out timing controls, including aircraft camera takeover. Refreshes preserve populated cards during transitions.
- Two-line owner names, expanded aircraft model names, full-width metrics, and improved fitting that prioritizes flight data over photos in small cards.
- Airport-Data joins Planespotters and Wikimedia Commons photo lookups. Exact-aircraft photos take priority; representative model photos remain labelled. Photo coverage is provider-dependent.
- Native photo download recovery and trusted redirect handling.

Validation: aircraft/backend checks, native UI tests, configuration tests, and browser checks for widget dragging/editing, appearance and photo layouts passed locally. Hosted release checks validate packaging and native playback. This release has not been installed or verified on MAIN-CAM-MONITOR.

Settings advance to schema 19. The first save retains settings.json.before-layout-widgets.json for rollback. To use an older release, stop RTSPView and restore that backup rather than loading the newer settings directly.

Select Settings → Updates → Beta to install this prerelease.

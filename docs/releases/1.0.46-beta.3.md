# RTSPView 1.0.46-beta.3

Based on beta.2. Settings remain schema 16; existing RTSP
sources retain their stored URLs and transport behavior.

- Direct HTTP/HTTPS media, HLS and DASH URLs can be configured alongside RTSP.
- Bundled Streamlink and yt-dlp resolve website sources into a local media relay.
- Source type and website quality controls are available in web and native editors,
  including own-source and linked picture-in-picture overlays.
- Test stream checks website extraction and receipt of media before applying.
- Reconnects resolve the original URL again. Helper startup is bounded and
  cancellable; tile disposal, replacement and parent exit clean up the helper.
- Packaging includes pinned Python dependencies, yt-dlp EJS, a checksum-verified
  Deno runtime and dependency notices.

See [setup and limitations](../website-streams.md). Authentication-cookie import,
DRM playback, separate-track muxing and standalone helper updates are outside
this initial integration. Website provider availability is not guaranteed.

Validation includes configuration and overlay propagation checks, real authenticated
HTTP/CSRF checks, packaged helper extraction and relay checks, native UI regressions,
and synthetic HTTP/HLS decoding with LibVLC. Browser checks cover save/reload and
linked-overlay preferences. No installed configuration or real cameras were changed.

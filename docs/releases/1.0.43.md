# RTSPView 1.0.43

This release brings the 1.0.43 beta features to Stable. Existing streams, saved layouts, credentials and update-channel preferences are retained.

- Redesigned Monitor, Streams, Layouts, Automations and Settings pages, including the stream editor drawer and active-layout overview.
- Standard and automation layouts support grids up to 12 × 12, custom output sizes, shared proportions, tile framing, zoom and pan, and per-layout borders and background colors.
- Secure pairing and stream/MQTT import for the optional Scrypted RTSPview connector. Install `scrypted-rtspview` from Scrypted; its current package is 0.1.0-beta.2 and remains a beta integration. Live Scrypted-host validation remains pending.
- Windowed **Full exit** leaves the Controller online and pauses automatic Viewer recovery. Start the Viewer from its desktop shortcut or Settings → Maintenance to resume. Maintenance disables Start viewer while it is already running or starting.
- Optional fullscreen hover exit in Settings → Display; the existing five-click fullscreen escape remains available.
- Explicit Viewer taskbar identity and matching shortcut/window icons. Windows shell appearance still needs confirmation on affected installations.

The automated release checks cover configuration, administrator security, connector pairing/import, automation, viewer lifecycle, native rendering, layouts and update helpers. Real camera/GPU behavior and live device integrations still depend on the host.

Tapo sensor integration is not included; that work starts in the next beta.

Download the Windows x64 installer and matching SHA-256 file below. This is a stable release, not a prerelease. Updating does not change the selected update channel automatically.

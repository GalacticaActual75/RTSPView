# RTSPView 1.0.44-beta.3

Automation now has aligned MQTT, Tapo and Priority tabs, with enable toggles for each integration.

- Discover H100/H200 hubs on the local network, select which to add, then discover T110 sensors. Manual hub entry remains available for networks that block discovery.
- Tapo rules can activate standard layouts or automation templates with a selected focus camera and an optional second camera. Sensor-driven overlay show/hide actions remain available.
- Reorder all MQTT and Tapo rules together in Priority using drag-and-drop or Move up/down. Save order assigns priority 1 to the top rule. Higher-priority views interrupt lower-priority automation.
- Both layout editors now offer New layout, starting blank or from a preset, alongside Duplicate. Add camera is renamed Add stream.
- Fit is the default image sizing for new tiles across layouts. Existing explicit sizing choices are preserved.

Includes beta.2 custom-overlay alignment across layout framing changes. Stable remains 1.0.43. Physical H100/H200/T110 validation is still pending; hub discovery and sensor actions were checked with simulated devices, backend tests and the native viewer.

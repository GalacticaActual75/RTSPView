# RTSPView 1.0.47-beta.11

Fix independent widget visibility in native Live View and improve the weather card layout.

- Weather and aircraft widgets now render in a transparent, click-through window above native camera video. The layer follows the wall, hides when minimized or suppressed by a dialog, and returns when the wall is restored.
- Aircraft widgets stay visible and editable on the Layouts canvas even when no aircraft are nearby. Hide when empty continues to apply to live display.
- Wide weather widgets use both sides of the card for the icon and a larger temperature reading, reducing unused space on the right. Portrait cards retain their vertical arrangement.

Validation: local browser checks confirmed empty-feed editor/live visibility and landscape/portrait weather presentation. Native UI and weather checks passed, including overlay window ownership, minimize/restore, layout isolation and right-side weather placement. Release automation runs the complete regression and native playback checks before publishing.

Settings remain schema 20. This release has not been installed or verified on MAIN-CAM-MONITOR.

On MAIN-CAM-MONITOR, select Settings → Updates → Beta to install this prerelease.

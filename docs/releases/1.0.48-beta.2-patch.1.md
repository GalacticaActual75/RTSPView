# RTSPView 1.0.48-beta.2 · Patch 1

This patch applies to Beta 1.0.48-beta.2 and fixes missing picture-in-picture previews and hard-to-find patch controls.

## Changes

- Standard and automation layout editors now show picture-in-picture snapshots with their saved size, shape, opacity and framing. Automation-only overlays appear as placement previews; their live visibility still follows automation rules.
- Selecting a focus preview camera also previews that camera's overlays. Each camera tile has direct overlay settings links, and the layout toolbar provides a Picture in picture panel.
- Saving overlay settings refreshes layout previews while retaining unsaved layout drafts.
- Settings → Updates has a dedicated Patches section showing the installed version, available patch, check times, Check for new patches and Install patch. The install button remains visible and is disabled when no patch is available.
- Automatic installation during scheduled restarts remains optional and off by default.

## Installing

On Beta 1.0.48-beta.2, open Settings → Updates and click Check for updates, then Install patch now under Application patches. After this patch is installed, use the new Patches section for future patch checks and installation.

Alternatively, download and run the Windows x64 installer attached to this release. Installation briefly stops the stream wall and restarts the application. This is a full installer package; existing settings are retained.

This patch does not replace Stable 1.0.47 or the normal Beta 1.0.48-beta.2 release listing. Automatic patch discovery requires that exact beta base.

## Validation

Focused browser checks cover overlay previews and settings navigation, preservation of layout drafts, patch checks, installation confirmation and simulated handoff, no-patch state, and narrow-screen layout. Automated release checks and native synthetic streaming playback run before publication. Testing does not install the patch on a live camera host.

# RTSPView 1.0.47-beta.9

Weather and aircraft widgets are now independent of camera tiles. Drag them anywhere on their saved layout, click to edit, and remove the selected widget using the Widgets panel or Delete. Undo restores removed widgets.

- One Add widget menu replaces duplicate weather and aircraft actions. Layout tools groups secondary controls, and toolbar/inspector spacing avoids overlapping controls.
- Existing camera-bound widgets and data tiles migrate to independent layout widgets while preserving settings and placement.
- Photo-enabled aircraft cards reserve image and credit space before metadata or image downloads arrive. Loading or failed photos no longer shift flight text.
- Improved photo lookup ordering, provider-specific cooldowns, and retries even when the traffic snapshot is unchanged. A labelled same-model photo can be used if no airline-matched photo is found.
- Fixed Monitor initialization before configuration is available, and aligned widget scaling between browser previews and Live View.

Validation: configuration, aircraft/backend, native UI, and LAN HTTP checks passed locally. Browser checks covered widget dragging, editing, removal, Undo, save/reload, panel bounds, and unchanged text geometry across all four aircraft card designs. Hosted release checks validate packaging and native playback.

Photo coverage remains provider-dependent. 99% is a target, not a measured result. This release has not been installed or verified on MAIN-CAM-MONITOR.

Settings advance to schema 20. The first save retains settings.json.before-independent-widgets.json for rollback. Stop RTSPView and restore that backup before returning to an older release.

Select Settings → Updates → Beta to install this prerelease.

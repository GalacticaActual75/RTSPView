# RTSPView 1.0.44-beta.1

This beta adds direct Tapo door-sensor automations and priorities. Stable remains 1.0.43, including the promoted dashboard and viewer exit/recovery/branding fixes.

- Configure H100/H200 hubs in the Automation tab and discover T110 sensors across both hubs. View Open, Closed and Unavailable status.
- Show or hide an overlay based on sensor state, independently of layouts. Optionally activate a saved wall layout and restore or choose another layout when the state clears.
- Set priority on every MQTT and Tapo rule. **1 is highest**: a priority-1 doorbell detection immediately interrupts a priority-2 garage view, including held views. Lower-priority actions resume only while still active.
- Test saved sensor rules using Open, Closed and Unavailable states. Passwords are encrypted; the local reader and its source/license bundle are included in the installer.

See [setup and behavior](https://github.com/GalacticaActual75/RTSPView/blob/codex/beta/docs/tapo-automation.md). Default Tapo polling is five seconds, so brief transitions may be missed. Physical H100/H200/T110 validation is pending; this is a beta for testing on your hardware.

Validation covers sensor parsing, state transitions, unavailable behavior, encrypted persistence, HTTP authorization/CSRF, native overlay visibility, layout arbitration, priority preemption/resume, existing MQTT regressions, and packaged reader startup.

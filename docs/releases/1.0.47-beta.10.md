# RTSPView 1.0.47-beta.10

Resize weather and aircraft widgets directly on the Layouts canvas using edge or corner handles. Width and height are independent; the aspect ratio is not locked.

- Content sizing uses the current card dimensions, preventing repeated resizing from progressively shrinking the text. Individual text-size preferences remain preserved.
- Tall weather cards use a vertical arrangement with a larger main reading and distributed details; wider cards return to a horizontal reading.
- Resizing updates the visible weather card even after a weather refresh. Aircraft detail fitting now uses consistent layout measurements at scaled preview sizes.
- Resize operations support Undo/Redo and persist through save/reload. Native Live View applies the same content scale.

Validation: browser checks covered corner/edge resizing, save/reload, Undo/Redo, refresh recovery, shrink/grow text-size restoration, and portrait-to-landscape reflow without overflow. Native UI, weather and browser regression checks passed locally; hosted checks validate the complete release and native playback.

Settings remain schema 20. This release has not been installed or verified on MAIN-CAM-MONITOR.

Select Settings → Updates → Beta to install this prerelease.

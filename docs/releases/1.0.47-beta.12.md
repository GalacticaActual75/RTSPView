# RTSPView 1.0.47-beta.12

Improve widget sizing, positioning and readability in the layout editor and native Live View.

- Fix native weather temperature clipping, including leading digits and negative signs. Enlarge high/low and secondary readings; short cards fit the primary reading before dropping the high/low row.
- Add exact wall-pixel position and dimensions, three size presets, nine alignment positions and Fit height to content in the Widgets panel. Width and height remain independently resizable. Arrow keys move widgets; Shift resizes and Alt makes fine adjustments.
- Use the saved wall resolution for widget edit previews. Consolidate positioning in the Layouts panel and start new widgets at more readable sizes.
- Give aircraft identity text more room beside the photo. Correct fitting order so available photos are not discarded before optional details are trimmed. Keep text positions stable when photos arrive.

Validation: native weather, aircraft and UI checks passed locally. Browser checks covered resizing, alignment, matching canvas/dialog geometry, larger readings and photo-arrival stability. The release workflow runs the full regression and native playback checks before publishing.

Settings remain schema 20; saved widget configuration is retained. These changes have not been installed or verified on MAIN-CAM-MONITOR. Photo availability still depends on provider results; the photo fitting fix does not guarantee a photo for every aircraft.

On MAIN-CAM-MONITOR, select Settings → Updates → Beta to install this prerelease.

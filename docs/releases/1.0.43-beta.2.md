# RTSPView 1.0.43-beta.2

Expanded layout controls for Standard View and Automation layouts:

- Independent Original (default), Fit, Fill and Stretch on every tile.
- Per-tile zoom, position sliders, image dragging and reset.
- Scaled output-resolution preview with HD, QHD, 4K, portrait, ultrawide and custom sizes.
- Up to 12×12 divisions, click/drag placement, edge/corner resizing, keyboard controls and undo/redo.
- Preserves automation focus positions and shared grid sizing from the previous beta.

Changes stay in draft until saved or applied. Output resolution does not change the Windows monitor mode. Actual camera-host rendering remains to be verified on the target hardware.

# RTSPView 1.0.46-beta.5

This beta repairs installation shutdown and improves failure diagnostics. It does not contain a confirmed YouTube live playback fix.

* Stop both scheduled and directly launched appliance supervisors before replacing application files. Verify that installed executable and DLL files are writable, and abort before replacement if a lock remains.
* Run shutdown preparation in updater workers too, so future updates and downgrades to older stable installers receive the same protection. Restore startup-task state after success or failure. Restore a running maintenance helper if installer preparation aborts after stopping it.
* Verify Controller, Viewer, and Maintenance versions before reporting update success. Preserve explicit installer logs on both update paths, date persisted failures, and explain/log why an update needs UAC instead of the helper.
* Serialize telemetry sampling with GPU counter discovery/disposal, addressing a race consistent with the reported `/api/telemetry` exception.
* Verify initial media bytes before announcing a website stream as ready. Report upstream HTTP 401/403 refusals instead of returning a relay URL that never produces video.

## Installation and limitations

The new installer contains the shutdown repair, including when launched by an older beta updater. Updating to this release may still require UAC if the currently installed helper is unavailable. An existing beta cannot acquire the new updater-worker logic until this installer succeeds. The updater repairs do not establish the particular cause of a helper being unavailable on a remote host.

The reported YouTube live stream still returns HTTP 403 for media segments in both the packaged resolver and yt-dlp's own client, using the current stable dependency. This release improves diagnosis, not access to that stream. No login, cookie import, or DRM support has been added.

The application log's converter errors align with thumbnail-capture timing, and displayed-frame counters continue afterward. Direct3D errors and dropped frames need verification on the affected GPU. Watchdog relaunches are not automatically classified as crashes. See [investigation notes](../update-repair-investigation.md).

## Validation

Regression checks exercise a real, directly launched synthetic supervisor holding a DLL, unrelated-process preservation, rejection of an unresolved file lock without modifying application bytes, staged-installer exclusion, and task restoration across retries. Update-worker checks cover hash rejection, installer failure, mixed component versions, and restart failure. Concurrent telemetry sampling, packaged helper media checks, and synthetic native RTSP/ONVIF/HLS/MP4 playback are included. The installer is compiled without installing it on the development host.

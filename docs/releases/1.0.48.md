# RTSPView 1.0.48

This stable release promotes all changes from 1.0.48-beta.2 through Patch 2, on top of the complete Stable 1.0.47 baseline.

## Picture-in-picture layouts

- Both Standard View and Automation layout editors preview overlay snapshots with their saved size, shape, opacity and framing. Automation-only overlays are shown as placement previews; live visibility still follows automation rules.
- Click an overlay directly to select it, drag it within its host camera, enter exact positions, or use arrow keys (Shift for larger steps). Small overlays remain clickable over camera resize handles.
- Remove from this layout hides an overlay only in the selected layout, including when an automation rule requests it. Restore to this layout brings it back; other layouts retain their own visibility and placement.
- Moves and removals support Undo/Redo and the normal layout save/apply controls. The Windows viewer honors these settings in standard and resolved automation layouts.
- Use shared position clears a local position override. Shared source, shape and display-mode settings remain available through Edit shared overlay settings.

## Dashboard consistency

- Corrected Display settings spacing and grouped monitor selection, identification and help.
- Consistent rounded cards, borders and spacing across settings, diagnostics, stream inventory and plugin panels; maintenance action cards have equal sizes.
- Aligned picture-in-picture actions and reduced excessive inspector gaps.
- Overlay deletion errors appear above the sidebar in an accessible dialog that identifies blocking layout or automation references, including disabled rules.

## Optional application patches

Settings → Updates → Patches shows the installed version, available patch and check times, with Check for new patches and Install patch controls.

Automatically install patches during scheduled restarts is off by default. When enabled, compatible patches for the installed release are checked daily and installed at an enabled Live View restart schedule, using an enabled maintenance helper that supports patches. Installation restarts the whole application and briefly interrupts the stream wall and dashboard. No enabled schedule means no automatic installation.

Turning auto-install off retains daily checks and manual installation and cancels pending automatic handoff unless the installer has already started. Full version upgrades and channel switches still require confirmation. Streaming-component updates keep their separate policy.

Future stable patches use identities such as 1.0.48-patch.1 and apply only to their exact base release. Patches currently use the full verified installer package. See [application patches](../application-patches.md) for details.

## Installing

Choose Stable in Settings → Updates, check for updates, and install 1.0.48, or run the attached Windows x64 installer. Existing settings are retained. Changing the selected channel alone does not install anything.

Users on 1.0.48-beta.2 or either beta patch should install this full stable release to move onto the 1.0.48 stable patch baseline. Beta patches are not stable patches.

## Validation

The beta releases passed configuration, update, scheduler, native viewer and JavaScript regression checks, plus native synthetic streaming playback. Isolated browser checks verified dashboard changes, patch controls, direct overlay selection/dragging, keyboard movement, removal/restoration, Undo/Redo, saving/reloading and layout isolation. The stable release pipeline repeats the full regression suite and native playback checks before publication. Automated validation does not install software or modify live camera-host settings.

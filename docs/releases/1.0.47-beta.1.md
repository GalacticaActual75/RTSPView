# 1.0.47-beta.1 — Aircraft widgets and flight-board tiles

Adds nearby aircraft to the camera wall through an ADSB.lol feed. Aircraft Widgets sit over a camera with the weather widget's background, opacity, corners and appearance controls. Standard layouts can replace a camera tile with a featured flight or a board of up to five nearby aircraft.

Configure a location, radius, altitude filters, displayed fields and units. Shared requests, old-position expiry, explicit outage states and rate-limit backoff keep aircraft updates separate from camera playback. Sample traffic is labelled in editors. Routes, airline logos and photos are not included.

Based on stable 1.0.46 application code plus current main's documentation updates. Settings upgrade to schema 17 with a retained pre-aircraft backup. See [Aircraft setup and rollback](../aircraft.md).

Also adds **Settings → Display → Windows startup** with actual scheduled-task status and an enable/disable/repair action. A sign-in launch now resumes Live View after an intentional stop in a previous session. Startup tasks use the interactive account, a 20-second sign-in delay, and allow battery operation. Changes can require Windows administrator approval on the host; the remote web browser reports the result.

Validation: Release compilation and all checks listed in tools/checks.ps1 passed across the completed runs, including native camera playback with aircraft presentation changes, authenticated HTTP APIs, startup service fixtures, browser layout checks, and installer shutdown tests. Installer syntax compilation passed with a synthetic staging directory; the release workflow packages the distributable installer after its checks pass. Windows sign-in must still be verified on the affected host after installation and startup-task repair.

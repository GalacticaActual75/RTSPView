# RTSPView 1.0.44-beta.4

Fixes maintenance controls from issue #11 and simplifies automation priority setup.

- Restart viewer uses the shorter label and is disabled while the viewer is stopped or starting.
- One full-screen button switches between Enter full screen and Exit full screen based on live viewer telemetry. It stays disabled when that status is unavailable.
- Quick actions beside Sign out offers the same immediate controls as Maintenance, with shared command feedback and existing restart/reboot confirmations.
- Priority fields are removed from MQTT and Tapo rule editors. Manage ordering and read priority behavior under Automation → Priority. Saving other rule changes preserves existing priorities.
- Automation help paragraphs use the full panel width instead of a narrow text column.

Includes beta.3 hub discovery, focus layouts, New layout, Add stream and Fit defaults. Stable remains 1.0.43. Physical Tapo hub validation is still pending.

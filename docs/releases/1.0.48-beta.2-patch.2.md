# RTSPView 1.0.48-beta.2 · Patch 2

Picture-in-picture camera overlays can now be selected, moved and removed directly in both Standard View and Automation layouts.

## Changes

- Click an overlay in the preview to select it and open its controls. Small overlays remain clickable when they overlap a host camera's resize handles.
- Drag within the host camera, enter exact horizontal/vertical positions, or use arrow keys (Shift for larger steps).
- Remove from this layout hides the overlay only in that layout. Other layouts retain it, and Restore to this layout brings it back. Layout removal also takes precedence over automation rules that show the overlay.
- Moves and removals support Undo/Redo and use the existing layout save/apply controls. The Windows viewer honors saved positions and removals in standard and automation layouts.
- Use shared position clears a layout's position override. Edit shared overlay settings still controls the common source, shape and display mode.

## Installing

On Beta 1.0.48-beta.2 Patch 1, open Settings → Updates → Patches, choose Check for new patches, then Install patch. This cumulative patch also supports the original 1.0.48-beta.2 release through its Application patches controls.

Alternatively, run the attached Windows x64 installer. Existing settings are retained; installation briefly restarts the application and stream wall. Optional automatic patch installation still uses your enabled scheduled restart.

This patch applies only to the 1.0.48-beta.2 base and does not replace the normal Beta or Stable release listing.

## Validation

Release build, configuration persistence/validation checks, native viewer checks and JavaScript regression checks passed locally. Browser verification covered direct selection, pointer dragging, keyboard movement, removal, restore, Undo/Redo, saving/reloading, and isolation between standard and automation layouts. The release pipeline runs the regression suite and native synthetic streaming playback before publication. No live camera-host installation was performed during testing.

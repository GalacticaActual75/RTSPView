# RTSPView 1.0.44-beta.7

This beta improves automation editing, diagnostics and recovery, and includes MQTT and Tapo automations in the normal web configuration backup.

- MQTT and Tapo use compact rule summaries, inline editors, consistent switches and Save/Discard controls. Draft changes and saved enabled state are shown separately; outdated saves are rejected without replacing the draft.
- Invalid targets are reported per rule while valid rules continue running. Integrations and rules can be disabled even when their targets are missing.
- Viewer acknowledgement is separate from viewer-reported priority winners and suppression reasons. Recent activity survives restarts and records rule decisions, sensor transitions, delivery results and priority changes. MQTT reports queue-drop counts.
- Reordering priorities preserves active detection episodes and Tapo tests. A recovery journal protects shared priority saves and configuration imports against Controller interruption. MQTT and Tapo keep three local settings backups and recover from the newest valid one.
- Web configuration export/import includes automation rules, priorities, mappings, zones, hubs and connection settings. Passwords are excluded. Existing compatible passwords are retained on import; integrations needing new credentials remain disabled. Older backups preserve existing automations.
- Every web administration page has a floating feedback button at the bottom left, with Buy me a coffee above it.

The installer updates the Viewer and Controller together. Viewer priority status reports arbitration, not successful video decoding. Physical Tapo H100/H200/T110 verification remains pending; automated checks use synthetic sensors. The native Viewer stream editor's export remains limited to stream/display settings; use web Settings for automation backups.

Validation: Release build; configuration, MQTT, Tapo, native Viewer and HTTP checks; interrupted-save and backup recovery tests; durable history and priority telemetry regressions; desktop/mobile browser checks.

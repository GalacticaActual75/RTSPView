# RTSPView 1.0.45-beta.2

Weather UI fixes on top of beta.1, retaining the stable v1.0.44 foundation.

- The weather editor follows the existing administration styling, with toggle switches for enable/field choices and sliders with values for appearance, size and position. The preview remains visible while scrolling on desktop.
- **Add weather** now opens a camera chooser when a grid is full, offering **Add weather overlay** or **Replace tile with weather**.
- Minimal overlays fit more closely around their contents. Their height grows with selected information, fixing high/low being present in the editor but missing from Live View after applying.
- Saved weather overlays appear as labeled placeholders in **Layouts**, matching their size and position. Applying or disabling an overlay updates the placeholder immediately; it persists after reload.
- The **Overlays** feature is now labeled **Stream Overlays**, including navigation and related actions. Weather overlays remain in **Layouts**.

Validation: native Minimal/high-low rendering at three text sizes, bounded overlay placement, camera decoding continuity, settings/security checks, desktop/mobile editor checks, full-grid choices and saved placeholder persistence. The release workflow runs the full existing regression suite before creating the installer.

Install through **Settings → Updates → Beta**, or download the Windows x64 installer below. Stable remains v1.0.44. Weather settings from beta.1 are retained.

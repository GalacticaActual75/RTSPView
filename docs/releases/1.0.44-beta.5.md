# RTSPView 1.0.44-beta.5

- Every MQTT and Tapo automation now has its own On/Off switch. Apply or save the form to enable or disable a rule without deleting its settings.
- Tapo discovery buttons have consistent spacing, and discovered hubs appear in separate padded rows.
- Remove Tapo account clears the email and encrypted password saved in RTSPView, disables Tapo automation, clears active sensor tests/effects and closes the reader connection. Saved hubs and rules are retained; the TP-Link account itself is not deleted. Removal asks for confirmation and discards unsaved Tapo edits.

Includes beta.4 Maintenance and Quick actions fixes, Priority-only ordering and full-width automation help. Stable remains 1.0.43.

Verified with backend security, credential-removal persistence and active-effect cleanup tests, plus browser checks of switches and hub spacing. Public repository privacy scans passed, including Git history. No user credentials or runtime configuration are included in the release.

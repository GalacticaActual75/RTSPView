# RTSPView 1.0.44

Stable 1.0.44 promotes the features and fixes from 1.0.44-beta.1 through beta.8. Existing streams, layouts and saved rules are retained when upgrading.

## Automation

- Direct Tapo H100/H200 hub discovery and T110 contact-sensor rules, with Open, Closed and Unavailable handling. Show/hide overlays or activate saved standard and automation layouts without Home Assistant or MQTT.
- One Automation Priority list for MQTT and Tapo. Reordering preserves active detection episodes and Tapo tests. Each integration and rule has its own enable switch.
- Compact summaries, inline editors, Save/Discard controls, protected drafts and stale-save detection. Invalid targets are isolated so valid rules continue running.
- Viewer priority winners and suppression reasons, separate from command acknowledgement. Persistent activity records decisions, sensor transitions and delivery results; MQTT exposes queue-drop counts.
- MQTT/Tapo automations included in normal web configuration exports. Passwords are omitted; imports retain compatible local credentials and disable integrations that need new passwords. Older files preserve existing automations.
- Three rolling automation backups and a recovery journal for interrupted shared priority saves and configuration imports.

## Layouts and controls

- Overlay Connection settings can reuse an existing main stream and follow its saved URL and connection settings. Overlay framing and visibility remain independent; configuration exports preserve the source link.
- Custom overlay masks and video follow host-camera framing, zoom and pan across layouts.
- New layout and Add stream controls in both layout editors, with Fit as the default for new tiles.
- Restart Live View and Restart Application distinguish the display process from the full application. Quick actions matches Maintenance and current viewer state.
- Stream, sensor and layout choices refresh while preserving automation drafts.
- Floating feedback and Buy me a coffee buttons on every web administration page.

The README now describes Stable 1.0.44 with current labels, setup steps, priority behavior and backup scope. Detailed beta history remains in the release notes.

Validation includes configuration, security/HTTP, MQTT, Tapo, native Viewer, restart/update helpers, connector, privacy and browser checks. Physical H100/H200/T110 validation remains pending; firmware compatibility varies. Viewer priority status does not confirm camera decoding. The separate Scrypted connector remains a beta component.

Download the Windows x64 installer below or use **Settings → Updates → Stable**. Back up before upgrading. Hosts on the Beta channel remain on beta releases until switched to Stable; selecting a channel does not install an update automatically.

# RTSPView 1.0.44-beta.8

Overlays can now reuse an existing main stream without entering its connection twice.

- In **Overlays → Connection → Video source**, choose a saved main stream or **Own RTSP URL**. Linked overlays follow the source's saved URL and connection settings automatically.
- Each overlay keeps its own name, display mode, shape, zoom, pan, placement and opacity. Overlay transforms never change the main tile. Playback uses a separate player and may open another camera connection.
- Configuration export/import preserves source links. Deleting a referenced main stream requires changing or detaching its overlay sources first.
- Source selection supports save, reload and discard; inherited connection fields are read-only. Existing separate URLs remain supported, including identical URLs in a main stream and overlay.
- README navigation, automation backup guidance and overlay setup instructions are updated. All beta.7 automation and feedback improvements are retained.

Validation: Release build, configuration persistence/export/import and deletion guards, isolated HTTP source propagation, native Viewer transform independence, browser save/reload/discard, related-choice and privacy checks. No physical camera playback was used for these checks.

Download the Windows x64 installer below or select Beta under **Settings → Updates**. This is a prerelease; Stable remains 1.0.43.

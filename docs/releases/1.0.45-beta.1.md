# RTSPView 1.0.45-beta.1

This beta starts directly from stable **v1.0.44** (`bfabd4e`) and adds native weather tiles and camera overlays. All stable 1.0.44 features are included. Weather is off until configured.

## Add weather

- Open **Layouts**. Use **Add weather** in an empty grid cell, or select a camera tile and choose **Replace with weather**. Choose a location, then apply the layout to the wall. A 3×3 layout can contain eight cameras and one weather tile.
- To put weather over a camera, select its tile and choose **Weather overlay**. Choose a location, appearance, size and corner or position, then **Apply overlay**. Clear **Enable weather overlay** to turn it off.
- Pick Minimal, Compact, Overlay, Detailed, Forecast or Dashboard. Choose individual readings, Fahrenheit or Celsius, colors, opacity, text/icon sizes, padding, alignment and rounded corners. Smaller cards omit details that cannot fit.
- Location search and manual coordinates are supported. Editor sample weather is explicitly labeled; the wall shows fetched data or an unavailable message.

## Data and playback

Open-Meteo supplies current temperature, conditions, feels-like temperature, high/low, humidity, wind, rain probability, sunrise/sunset and hourly/daily forecasts. No account or API key is needed for this noncommercial application. Coordinates are sent to Open-Meteo. Attribution appears on the cards. See [Open-Meteo](https://open-meteo.com/) and the [CC BY 4.0 data license](https://creativecommons.org/licenses/by/4.0/).

Locations share cached data, refreshed approximately every 15 minutes. Weather downloads run separately from video playback. Cached readings show an outdated/failure status when appropriate; readings older than six hours are hidden. Camera overlays use native WPF content without a browser or extra video player.

This first beta supports weather tiles in standard layouts and one weather overlay per main camera. It does not include official severe-weather alerts, backdrop blur, or weather tiles in automation layout templates. Forecast details depend on available space. Preview appearance can differ slightly from the native wall.

## Upgrade and rollback

Settings advance to schema 16. On the first settings save, the original pre-weather file is retained as `settings.json.before-weather.json` in the RTSPView data directory. Weather is included in normal configuration exports. To return to stable 1.0.44, stop RTSPView, restore that pre-weather file as `settings.json`, and install stable; the beta settings file cannot be used directly by the older release.

## Validation

Checked live Open-Meteo response parsing, location time zones/DST, missing measurements, expired data, shared requests, migration and rollback backup, configuration import/export, HTTP authorization and CSRF, desktop/mobile editors, native rendering, and weather overlay changes during actual fixture decoding. Camera layout, automation, Tapo, restart, and existing native Viewer regression checks also pass. Hosted release checks package the Windows x64 installer.

Download the installer below, or select **Settings → Updates → Beta** and check for updates. Stable remains v1.0.44. No automatic installation is performed by this release.

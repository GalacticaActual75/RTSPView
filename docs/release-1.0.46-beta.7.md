# RTSPView 1.0.46-beta.7

Modern Dark redesign of the **web admin panel only**. Windows Live View appearance, playback, automation, and kiosk behavior are unchanged.

- Collapsible sidebar with all six sections, stream health, Buy Me a Coffee, feedback, and sign-out.
- Camera-focused Monitor, refined stream inventory, grouped layout tools, and a PiP canvas with a property inspector.
- Consistent dark controls, typography, settings sections, dialogs, status colors, and responsive layouts.
- Readable automation summaries: When, Then, For / until, and Afterward; existing rule capabilities and save scopes retained.
- Custom confirmations replace browser dialogs. Destructive actions identify their target; successful saves use nonblocking notifications.
- As requested, closing/reloading a tab no longer displays a native warning. Save edits before closing/reloading; in-app navigation retains drafts and sign-out confirms discarding them.

Validation includes the Controller build, UI/security regression checks, and browser testing across desktop, tablet, and phone sizes. Camera-host playback was not exercised by the UI fixture.

RTSPView's project-owned source currently has **no open-source license grant**. Public source availability does not by itself grant permission to reuse, modify or redistribute it. No new license grant is made by this documentation. Obtain permission from the relevant rights holders for uses requiring such permission.

The Scrypted connector retains its existing npm package status, **UNLICENSED**. A future choice of MIT, Apache-2.0 or another license requires an explicit project-owner decision; this update does not make that choice.

Third-party components retain their own licenses. In particular, the Tapo reader has its own [license](../integrations/tapo-reader/LICENSE), and its packaged release includes dependency notices and corresponding source distribution. LibreHardwareMonitor's [license](../src/RTSPView.Controller/ThirdParty/LibreHardwareMonitor-LICENSE.txt) and [notices](../src/RTSPView.Controller/ThirdParty/LibreHardwareMonitor-NOTICES.txt), LibVLC and other bundled dependencies must be considered separately. This page does not relicense those components.

Weather data attribution and provider service terms are separate from the application's source-code licensing. See [Open-Meteo's license](https://open-meteo.com/en/licence) and [terms](https://open-meteo.com/en/terms).

## Aircraft data

The optional aircraft integration queries [ADSB.lol](https://www.adsb.lol/docs/open-data/api/), which lists API data under ODbL 1.0. Aircraft widgets and tiles display provider/license attribution. No FlightWall source code, branding, artwork, or airline logos are included.
